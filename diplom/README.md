# Adeline — сайт элитного жилого комплекса

Учебный проект: многостраничный сайт жилого комплекса бизнес-класса. Реализован на **Laravel** с использованием **Blade**, **Alpine.js** и **Tailwind CSS**.

## 🚧 Статус проекта

Проект находится в разработке. Реализовано:

- ✅ Вёрстка всех страниц (главная, каталог квартир, карточка квартиры, личный кабинет, регистрация/авторизация)
- ✅ Фильтрация квартир (Alpine.js + запросы к БД)
- ✅ Swiper-слайдеры
- ✅ Аккордеоны, табы, hover-эффекты
- ✅ Хранение квартир в БД (Laravel + MySQL)
- ✅ Компонентный подход в Blade

В планах:

- ⏳ Логика личного кабинета
- ⏳ Обработка форм

## 🛠️ Стек технологий

- **Backend:** Laravel, PHP
- **Frontend:** Blade, Alpine.js, Tailwind CSS
- **Слайдеры:** Swiper
- **БД:** MySQL
- **Изображения:** Cloudinary
- **Сборка:** Vite
